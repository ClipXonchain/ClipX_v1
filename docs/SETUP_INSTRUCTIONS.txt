  ClipX VPS Deployment Instructions - clipx.app
═══════════════════════════════════════════════════════════════

📁 Deployment Path: /root/release2
🌐 Domain: clipx.app
🤖 Bot: /root/release2/bot/nativebot.py (uses venv)

═══════════════════════════════════════════════════════════════

🚀 QUICK START (Copy & Paste)
═══════════════════════════════════════════════════════════════

# 1. Navigate to project directory
cd /root/release2

# 2. Run automated setup script
bash DEPLOY.sh

# 3. Configure .env file (if not already done)
nano .env
# Paste your environment variables, save with Ctrl+X, Y, Enter

# 4. Setup Nginx for clipx.app
sudo cp nginx-clipx.conf /etc/nginx/sites-available/clipx
sudo ln -s /etc/nginx/sites-available/clipx /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# 5. Get SSL certificate for clipx.app
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d clipx.app -d www.clipx.app

# 6. Install PM2 (if not installed)
npm install -g pm2

# 7. Start application with PM2
pm2 start ecosystem.config.cjs --env production
pm2 save
pm2 startup
# Copy and run the command that pm2 startup outputs

# 8. Check if everything is running
pm2 list

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Server not starting:
-------------------
pm2 logs clipx-server --lines 50
ls -la /root/release2/dist/index.js
pm2 restart clipx-server

Bot not starting:
----------------
pm2 logs clipx-bot --lines 50
ls -la /root/release2/venv/bin/python3
ls -la /root/release2/bot/nativebot.py
cd /root/release2 && source venv/bin/activate && python3 bot/nativebot.py

Database connection:
-------------------
cat .env | grep DATABASE_URL

Nginx issues:
------------
sudo nginx -t
sudo tail -f /var/log/nginx/error.log
sudo systemctl status nginx
